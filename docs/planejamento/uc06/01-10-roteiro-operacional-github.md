# Artefato 10 — Roteiro operacional de configuração no GitHub

1. Acesse o repositório `Vagaacil/vaga-facil` no GitHub.
2. Confirme que a Issue principal não existe antes de criar a Epic.
3. Crie uma Issue com título `[UC06] Cadastrar Pátio e Vagas` usando o conteúdo do Artefato 3.
4. Crie as sete Sub-Issues em ordem de prontidão, usando os títulos e conteúdos do Artefato 4.
5. Vincule a Issue principal às Sub-Issues por tasklist ou referência explícita.
6. Adicione a Issue principal uma checklist das SUB-01 a SUB-07.
7. Crie as labels planejadas no Artefato 7, revisando conflitos de nomes existentes.
8. Aplique `uc06`, o tipo, a camada e prioridade correspondente a cada Issue.
9. Crie um GitHub Project em modo Board/Kanban.
10. Configure exatamente os campos `Backlog`, `Ready`, `In Progress`, `In Review` e `Done` no Status.
11. Remova ou ignore estados divergentes que o template padrão possa apresentar.
12. Insira Epic e todas as Sub-Issues no Project.
13. Mantenha todas as questões no Backlog até haver decisões de especificação e Definition of Ready.
14. Use SUB-01 para levantar/resolver campos, fluxos, regras e autorização antes de tornar trabalhos dependentes prontos.
15. Atribua responsáveis somente quando definidos pela equipe.
16. Revise referências cruzadas, links entre Issues, labels, status, responsáveis e rastreabilidade.
17. Faça uma revisão final para impedir que atividades fiquem bloqueadas por dependências circulares.
